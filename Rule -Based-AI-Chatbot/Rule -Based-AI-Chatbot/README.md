#Rule-Based AI Chatbot

#Project Description

This project is a simple Rule-Based AI Chatbot developed using Python. The chatbot responds to predefined user inputs using rule-based logic.

#Features

- Greets the user
- Answers simple predefined questions
- Responds to "thank you" and "thanks"
- Exits when the user types "bye" or "exit"

#Technologies Used

- Python
- Visual Studio Code

#How to Run

1. Open the project in Visual Studio Code.
2. Open the terminal.
3. Run:
   python chatbot.py
4. Start chatting with the bot.
