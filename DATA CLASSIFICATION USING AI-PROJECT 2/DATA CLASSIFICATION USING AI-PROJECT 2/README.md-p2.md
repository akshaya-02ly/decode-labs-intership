# Iris Flower Classification using Decision Tree

## 📌 Project Overview
This project is a simple **Machine Learning classification system** that predicts the species of an Iris flower using the **Decision Tree algorithm**.

It is built using Python and Scikit-learn and is one of the most popular beginner-level ML projects for understanding classification concepts.

##  Objective
To classify Iris flowers into three species:
- Setosa
- Versicolor
- Virginica

based on the following features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Machine Learning Concept
- Supervised Learning
- Classification Problem
- Decision Tree Algorithm

## Technologies Used
- Python 3
- Scikit-learn
- Train-Test Split
- Model Evaluation Metrics

##  Project Workflow
1. Load Iris dataset from `sklearn.datasets`
2. Split dataset into training and testing sets
3. Train a Decision Tree Classifier
4. Make predictions on test data
5. Evaluate model performance using metrics

## Model Evaluation

The model is evaluated using:
- Accuracy Score
- Confusion Matrix
- Classification Report

##  Results
- The model achieved high accuracy on the Iris dataset
- Decision Tree performs well due to clear class separation
- Evaluation metrics confirm strong classification performance
